### What it does
- **Sessions that outlive the connection** - lock the phone, change networks, come back to the same shell.
- **Terminal built for touch** - a customizable key toolbar, split panes, local echo on slow links.
- **Files over SFTP** - browse, edit, upload and download next to the terminal.
- **Jump hosts, port forwarding, snippets** - the things you reach for every day.
- **Free, with nothing gated** - no ads, no in-app purchases, no paid tier.
